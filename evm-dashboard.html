Construction Project EVM Dashboard

Problem

Leadership had no unified view of project health across a multi-project construction portfolio. Schedule data lived in one system, budget data in another, and status updates were buried in email threads. By the time a project slipped, it was often too late to course-correct — and no one could quickly answer the question that mattered most: which projects are actually at risk right now?

The reporting that did exist was retrospective and static. A monthly PDF told you where things stood three weeks ago. It didn't distinguish a project that was behind schedule but under budget from one that was burning cash to stay on time — two situations that call for opposite interventions.

Process

I designed a consolidated Tableau dashboard around four integrated views, each answering a different question a program executive would ask in sequence.

Earned Value Management. The core module plots three cumulative curves — BCWS (planned value), BCWP (earned value), and ACWP (actual cost) — against a vertical "today" marker. From those, Schedule Performance Index and Cost Performance Index surface as headline KPIs. The value of EVM here is that it separates the two failure modes: a project can be behind schedule, over budget, or both, and the curves make which one immediately legible.

Gantt schedule tracking. Percent-complete against plan for every active project, with progress bars inheriting a status color so the portfolio reads at a glance.

Baseline versus current budget. Paired horizontal bars per project. Putting baseline directly above current forecast means variance is a visual gap rather than a number the reader has to compute.

Color-coded notes log. The piece I'd point to first. Each note inherits a border color from the project's RAG status at the time it was written. This turns qualitative commentary — usually the least structured data in project management — into a scannable risk signal. A cluster of red-bordered notes on one project is visible before anyone reads a word.

Result

The dashboard became the standing artifact for executive project reviews. Status questions that previously required a data pull now resolve in the meeting itself, and the notes log surfaced schedule risks earlier in the project lifecycle by making patterns visible that were previously spread across individual updates.

The outcome I found most useful was pedagogical: the EVM view made cost and schedule performance legible to stakeholders who had never worked with earned value methodology. SPI and CPI stopped being jargon once people could see the curves that produced them.

A note on this demo. The linked dashboard is a recreation built for portfolio purposes. All project names, budget figures, dates, and notes are fictional. No proprietary or employer-confidential data is represented. The structure, calculations, and design decisions reflect the original work.
